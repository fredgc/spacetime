# 2. 恒定光速与相对性

光速恒定到底意味着什么？

## 1. 以太论与发射源论

在爱因斯坦之前，物理学家发现光在真空中的传播速度是恒定的。但相对于什么恒定呢？

爱因斯坦从一个思想实验出发。如果我们坐在一列喝着茶、离开北京站的火车上并发出闪光，光速是相对于地面恒定，还是相对于列车恒定？

* **以太论**：光是在绝对静止的宇宙介质（“光以太”）中传播的波动。光相对于以太的速度永远是$c = 1$，无论光源如何运动。

* **发射源论**：光是由光源以相对于发射源自身为$c = 1$的速度射出的粒子流。
  若光源以速度$v$运动，则向前发出的光速为$c + v$，向后为$c - v$。

我们通过运动的列车来验证这两种理论。首先测试发射源假设。我在地面参考系（$v = 0$）中放置了两面旗帜。

切换到**使用发射源速度**并将观察者速度设置为$v = 0.25$。

> reset
> setup: v=0.0, t=0.0, mode=lorentz, tool=select
> object: flag(name="BF", x=-0.25, t=0.0, v=0.0, color=teal)
> object: flag(name="FF", x=0.25, t=0.0, v=0.0, color=teal)
> mode = emitter
> v = 0.25

## 2. 两端闪光的列车

在此参考系（$v = 0.25$）中，已放置：

* 一列从$x = -0.25$延伸至$x = 0.25$的**列车**（中心位于$x = 0.0$）。

* 在$t = 0.0$时从列车车尾（**B**）和车头（**F**）向车厢内部发出的两道闪光（橙色）。

> setup: v=0.25, t=0.0, mode=emitter, tool=select
> object: train(name="Train", x=-0.25, t=0.0, v=0.25, color=purple)
> object: cone(name="B", x=-0.25, t=0.0, v=0.25, z=0.15, color=orange)
> object: cone(name="F", x=0.25, t=0.0, v=0.25, z=0.15, color=orange)

将**时间**滑块推进到$t = 0.25$。

注意到在该参考系中两道闪光速度均为1，并在列车正中央相遇。

> t = 0.25

## 3. 发射源论：地面视角

切换到地面参考系（$v = 0.0$）并将时间重置到$t = 0.0$。

光锥在地面参考系中的斜率发生了倾斜。

> v = 0.0
> t = 0.0

## 4. 发射源论：推进时间

将**时间**滑块推进到$t = 0.5$。

两道闪光依然在$t = 0.5$时相遇，但并没有在两面旗帜的正中央相遇，因为其中一道闪光在地面看更快。

> t = 0.5

## 5. 以太论：地面视角

回到$t = 0.0$并切换到**使用以太假说**模式。

> t = 0.0
> mode = ether

## 6. 以太论：光束在中央相遇

将**时间**推进到$t = 0.25$。

闪光精确在两面旗帜的中央相遇，因为相对于静止的以太，光速向各个方向都是完全一样的。

> t = 0.25

## 7. 以太论：列车视角

回到$t = 0.0$并切换到列车参考系（$v = 0.25$）。

> t = 0.0
> v = 0.25

## 8. 以太论：光束错过列车中央

推进**时间**至$t = 0.25$。

两道光束没有在列车中央相遇！因为在列车参考系中，前后光速并不对称。

> t = 0.25

## 9. 为什么会错过中央

在以太模型中，光相对于地面以太传播，而非列车。由于列车向前运动：

* 车头光束（**F**）以$1 + 0.25 = 1.25$扑向中央，过早到达（$t = 0.20$）。

* 车尾光束（**B**）以$1 - 0.25 = 0.75$艰难追赶，较晚到达（$t = 0.33$）。

以太论预测两道光在列车中央无法同时相遇！
