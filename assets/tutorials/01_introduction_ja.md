# 1. はじめに：Spacetime ツールの使い方

ミンコフスキー時空図の描き方、オブジェクトの編集方法、基準系の探索方法を学びます。

## 1. 画面表示の説明

相対論的時空図作図ツールへようこそ！画面は上下2つのビューに分かれています：

* **時空図（上）**：水平軸が空間（$x$）、垂直軸が時間（$t$）を表します（光速度$c = 1$の単位系）。

* **観測者ビュー（下）**：現在の時刻$t$（時空図の水平バーで表示）に観測者から見える1Dアニメーションを表示します。

**次へ**をクリックしてオブジェクトの配置を開始しましょう。

> reset
> setup: v=0.0, t=0.0, mode=lorentz
> ok

## 2. 事象（イベント）の追加

図の上のツールバーで**選択**と**追加**を切り替え、作成するオブジェクトの種類を選べます。

ツールを**追加**に切り替え、**事象**を選び、時空キャンバス上の点滅するターゲット$(x = 0.0, t = 0.5)$をクリックします（または
**自動で実行**をクリック）。

> add = event(x=0.0, t=0.5)

## 3. 世界線・光円錐・同時面

単一の事象に加えて、以下のオブジェクトを描画できます：

* **位置（観測者、列車、車庫、旗、時計）**：時間の中を運動する物体の軌跡（世界線）。

* **光円錐**：傾き$\pm 1$（$c = 1$のため）で左右に広がる2本の光線。

* **同時面**：ある観測者にとって同一時刻に起こるすべての事象を結ぶ直線。

**追加**が有効な状態で**光円錐**を選び、原点$(x = 0.0, t = 0.0)$をクリックして閃光を追加します。

> add = cone(x=0.0, t=0.0)

## 4. オブジェクトの選択

既存のオブジェクトを調べたり編集したりするには、**選択**に切り替えて図上のオブジェクトをクリックします。（空白をドラッグすると画面をスクロールできます。
）

$x = -0.5$に**Alice**という観測者を追加しました。**選択**に切り替えてAliceの世界線をクリックしてください。

> object: person(name="Alice", x=-0.5, t=0.0, v=0.0, color=blue)
> select = Alice

## 5. オブジェクトの移動と編集

オブジェクトを選択すると、上部ツールバーで名前や色を変更したり、削除したり、キャンバス上の新しい位置へドラッグしたりできます。

**Alice**を右側の$x = 0.5$までドラッグしてください（または**自動で実行**をクリック）。

> move = Alice(x=0.5, tol=0.25)

## 6. 時間の進行アニメーション

観測者ビューの下にある**時間**スライダーは、時空図の時刻$t$を上下に移動させます。

$x = -0.25$に静止した**列車**を配置し、**Alice**を速度$v = 0.5$で右へ移動させました。**時間**スライダーを$t =
0.5$まで動かし、光線が広がり、事象が点滅し、Aliceが列車を通過する様子を観察してください！

> reset
> setup: v=0.0, t=0.0, mode=lorentz, tool=select
> object: event(name="E1", x=0.0, t=0.5, color=red)
> object: cone(name="L1", x=0.0, t=0.0, color=orange)
> object: train(name="Train", x=-0.25, t=0.0, v=0.0, color=green)
> object: person(name="Alice", x=0.0, t=0.0, v=0.5, color=blue)
> t = 0.5

## 7. 観測者基準系の速度変更

時間スライダーの下には**速度**スライダーがあります。これは私たちの基準系の速度$v$を制御します。新しく追加されたオブジェクトは現在の観測者速度を継承し
ます。

**速度**スライダーを$v = 0.50$に移動し、Aliceの基準系に切り替えてみましょう。

> v = 0.5

## 8. 運動の相対性

Aliceの基準系（$v = 0.50$）では、Aliceの世界線は垂直（静止）になり、列車の世界線が左に傾きます！

物理法則は相対的であるため、列車がAliceを通過すると言うのも、$v = 0.0$に戻ってAliceが列車を通過すると言うのも同等に正しく成立します。

**次へ**をクリックして入門チュートリアルを完了してください！

> ok
