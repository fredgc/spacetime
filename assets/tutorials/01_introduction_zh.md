# 1. 入门：使用时空图绘制工具

学习如何绘制闵可夫斯基时空图、编辑物理对象以及探索参考系。

## 1. 界面视图说明

欢迎使用相对论时空图绘制工具！屏幕分为上下两个视图：

* **时空图（上方）**：水平轴为空间坐标（$x$），垂直轴为时间坐标（$t$），在光速为$c = 1$的自然单位制下显示。

* **观察者视图（下方）**：显示当前瞬时时刻$t$（由时空图中的水平指示线标出）观察者所看到的1D动画切片。

点击**继续**开始在图表中放置对象。

> reset
> setup: v=0.0, t=0.0, mode=lorentz
> ok

## 2. 添加一个事件

图表上方的工具栏允许您在**选择**与**添加**之间切换，并选择要创建的对象类型。

将工具切换为**添加**，选择**事件**，然后点击时空画布上闪烁的目标点$(x = 0.0, t = 0.5)$（或点击**帮我完成**）。

> add = event(x=0.0, t=0.5)

## 3. 世界线、光锥与瞬时面

除单个事件外，您还可以绘制：

* **运动物体（观察者、列车、车库、旗帜、时钟）**：表示在时间中运动的物体的轨迹（世界线）。

* **光锥**：以斜率$\pm 1$（因为$c = 1$）向左右展开的两道光线。

* **瞬时面**：连接对特定观察者来说在同一时刻发生的所有事件的直线。

在**添加**模式下，选择**光锥**并点击原点$(x = 0.0, t = 0.0)$发出一道闪光。

> add = cone(x=0.0, t=0.0)

## 4. 选择对象

要检查或修改现有对象，请切换到**选择**模式并点击图表中的对象。（在空白处点击并拖动可平移画布。）

我们在$x = -0.5$处添加了一个名为**Alice**的观察者。切换到**选择**并点击Alice的世界线以选中她。

> object: person(name="Alice", x=-0.5, t=0.0, v=0.0, color=blue)
> select = Alice

## 5. 移动与编辑对象

选中对象后，您可以在顶部工具栏中修改其名称或颜色、将其删除，或将其拖动到画布上的新位置。

将**Alice**向右拖动到$x = 0.5$（或点击**帮我完成**）。

> move = Alice(x=0.5, tol=0.25)

## 6. 时间模拟

观察者视图下方是**时间**滑块，用于上下移动时空图中的当前时间切片$t$。

我们在$x = -0.25$处放置了一列静止的**列车**，并让**Alice**以速度$v = 0.5$向右运动。将**时间**滑块移动到$t =
0.5$，观察光线展开、事件闪烁以及Alice驶过列车的全过程！

> reset
> setup: v=0.0, t=0.0, mode=lorentz, tool=select
> object: event(name="E1", x=0.0, t=0.5, color=red)
> object: cone(name="L1", x=0.0, t=0.0, color=orange)
> object: train(name="Train", x=-0.25, t=0.0, v=0.0, color=green)
> object: person(name="Alice", x=0.0, t=0.0, v=0.5, color=blue)
> t = 0.5

## 7. 改变观察者参考系速度

时间滑块下方是**速度**滑块。它控制我们观察参考系的速度$v$。任何新添加的对象都会自动继承当前观察者的速度。

将**速度**滑块调节到$v = 0.50$，切换到Alice的静止参考系中。

> v = 0.5

## 8. 运动的相对性

在Alice的参考系（$v = 0.50$）中，Alice的世界线是垂直的（她处于相对静止状态），而列车的世界线则向左倾斜！

由于物理定律具有相对性，说列车驶过Alice，与回到$v = 0.0$说Alice驶过列车是完全等价的。

点击**继续**完成入门教程！

> ok
