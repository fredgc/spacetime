# 2. 光速度不変と相対性

光速度が一定であるとはどういう意味でしょうか？

## 1. エーテル論 vs 光源速度論

アインシュタイン以前、科学者たちは真空中での光速度が一定であることを発見していました。しかし、何に対して一定なのでしょうか？

アインシュタインは思考実験から始めました。お茶を飲みながら東京駅を出発する列車に乗って閃光を放ったとき、その光の速さは地面に対して相対的なのか、それとも列車
に対して相対的なのか？

* **エーテル理論**：光は静止した宇宙媒質（エーテル）を伝わる波である。光源の運動に関わらず、光速度はエーテルに対して常に$c = 1$である。

* **光源速度説**：光は光源から光源に対して速度$c = 1$で放たれる粒子である。
  光源が速度$v$で動く場合、前方の光は$c + v$、後方の光は$c - v$で進む。

運動する列車で両方の理論を検証してみましょう。まず光源速度説を検証します。$v = 0$の基準系に旗を2本配置しました。

**光源速度を使用**に切り替え、観測者速度を$v = 0.25$に設定します。

> reset
> setup: v=0.0, t=0.0, mode=lorentz, tool=select
> object: flag(name="BF", x=-0.25, t=0.0, v=0.0, color=teal)
> object: flag(name="FF", x=0.25, t=0.0, v=0.0, color=teal)
> mode = emitter
> v = 0.25

## 2. 両端で閃光を放つ列車

この基準系（$v = 0.25$）には次を配置しています：

* $x = -0.25$から$x = 0.25$までの**列車**（中心$x = 0.0$）。

* $t = 0.0$に列車の後端（**B**）と前端（**F**）から内側に向けて放たれた2つの閃光（オレンジ色）。

> setup: v=0.25, t=0.0, mode=emitter, tool=select
> object: train(name="Train", x=-0.25, t=0.0, v=0.25, color=purple)
> object: cone(name="B", x=-0.25, t=0.0, v=0.25, z=0.15, color=orange)
> object: cone(name="F", x=0.25, t=0.0, v=0.25, z=0.15, color=orange)

**時間**スライダーを$t = 0.25$に進めます。

この基準系では両方の閃光が速度1で進み、列車の中央で出会うことがわかります。

> t = 0.25

## 3. 光源速度説：地面からの視点

地面の基準系（$v = 0.0$）に切り替え、時間$t = 0.0$に戻します。

地面から見ると光線の傾きが変わります。

> v = 0.0
> t = 0.0

## 4. 光源速度説：時間を進める

**時間**スライダーを$t = 0.5$に進めます。

閃光は$t = 0.5$で出会いますが、2本の旗の中央では出会いません。地面から見ると一方の光が速いためです。

> t = 0.5

## 5. エーテル論：地面からの視点

$t = 0.0$に戻し、**エーテル仮説を使用**に切り替えます。

> t = 0.0
> mode = ether

## 6. エーテル論：中央で出会う光

**時間**を$t = 0.25$に進めます。

旗の基準系において光速度は両方向に等しいため、2本の旗のちょうど中央で出会います。

> t = 0.25

## 7. エーテル論：列車からの視点

$t = 0.0$に戻し、列車の基準系（$v = 0.25$）に切り替えます。

> t = 0.0
> v = 0.25

## 8. エーテル論：列車の中央を外れる光

**時間**を$t = 0.25$に進めます。

列車に対して光の速さが前後で異なるため、列車の中央では出会いません。

> t = 0.25

## 9. エーテル論：なぜずれるのか

エーテルモデルでは、光は列車ではなく地面のエーテルに対して$c = 1$で進みます。列車が前進するため：

* 前方の光（**F**）は$1 + 0.25 = 1.25$で中央に向かい、早く到達（$t = 0.20$）。

* 後方の光（**B**）は$1 - 0.25 = 0.75$で追いかけるため、遅く到達（$t = 0.33$）。
