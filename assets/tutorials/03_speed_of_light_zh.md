# 3. 恒定光速与同时性的相对性

探索为何不同观察者对两个事件是否“同时发生”存在分歧，以及这种同时性的相对性为何是光速恒定的必然结果。

## 1. 带有中心闪光的列车

让我们从以$v = 0.25$运行的列车参考系开始。

列车静止长度为$0.50$（$x = -0.25$至$x = 0.25$）。选择**添加**中的**光锥**，并在下方观察者视图中点击列车中心$(x =
0.0, z = 0.15)$发出闪光。

> reset
> setup: v=0.25, t=0.0, mode=lorentz, tool=add, type=cone
> object: train(name="Train", x=-0.25, t=0.0, v=0.25, color=purple)
> add = cone(name="Flash", x=0.0, t=0.0, z=0.15, color=orange, side=true)

## 2. 列车参考系中的同时击中

推进**时间**至$t = 0.25$。

在列车参考系中，光速在两端对称传播。两道光在完全相同的时刻（$t = 0.25$）击中车头和车尾！

> t = 0.25

## 3. 切换至地面参考系

将**速度**设置为$v = 0.00$，时间置于$t = 0.00$。根据狭义相对论（**洛伦兹变换**），即使列车在运动，光速仍然是$c =
1$（$45^\circ$斜率）！

> v = 0.0
> t = 0.0

## 4. 光击中车尾

推进**时间**至$t = 0.19$。车尾迎着反向传播的光运动，在$t \approx 0.19$时提前相遇。

> t = 0.19

## 5. 标记事件 B

选择**添加**中的**事件**，在$(x = -0.19, t = 0.19)$处放置事件**B**（车尾击中）。

> add = event(name="B", x=-0.19, t=0.19, color=red)

## 6. 光击中车头

将**时间**推进至$t = 0.32$。车头远离光源运动，前向光束经过更长时间才在$t \approx 0.32$处追上车头。

> t = 0.32

## 7. 标记事件 F

在$(x = 0.32, t = 0.32)$处标记事件**F**（车头击中）。

> add = event(name="F", x=0.32, t=0.32, color=green)

## 8. 返回列车参考系

将**速度**滑块调回$v = 0.25$。

> reset
> setup: v=0.0, t=0.32, mode=lorentz, tool=select
> object: train(name="Train", x=-0.25, t=0.0, v=0.25, color=purple)
> object: cone(name="Flash", x=0.0, t=0.0, z=0.15, color=orange)
> object: event(name="B", x=-0.19, t=0.19, color=red)
> object: event(name="F", x=0.32, t=0.32, color=green)
> v = 0.25

## 9. 再次同时！

将**时间**设置为$t = 0.25$。在列车系中，事件**B**与**F**再次完全同时发生！

参考系切换导致同时性平面发生倾斜：

* 在列车参考系中，两者**同时**发生（$t = 0.25$）。

* 在地面参考系中，**B**先发生（$t = 0.19$），**F**后发生（$t = 0.32$）。

> t = 0.25

## 10. 同时性的相对性

绝对同时性并不存在。相对运动的观察者对空间上分离的事件发生顺序必然得出不同结论。

> ok
