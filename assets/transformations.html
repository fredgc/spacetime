Relativistic Transformations

The Spacetime Drawing Tool allows you to explore how coordinates transform under different physical hypotheses for the speed of light:

1. Lorentz (Special Relativity)

According to Einstein’s theory of Special Relativity, the speed of light (c=1.0c = 1.0) is constant and identical in all inertial reference frames.

  • Coordinates transform using the Lorentz transformation:

    x′=γ(x−vt)x' = \gamma (x - v t)

    t′=γ(t−vx)t' = \gamma (t - v x)

    where γ=1/1−v2\gamma = 1 / \sqrt{1 - v^2}.

  • This results in length contraction, time dilation, and the relativity of simultaneity.

2. Ether

The Ether hypothesis assumes there is a single, preferred global reference frame (the “ether”) in which light travels at speed c=1.0c = 1.0.

  • In any reference frame moving at velocity vv relative to the ether, the speed of light is relative and depends on the direction of propagation (c′=c±vc' = c \pm v).

  • This is a classical Newtonian model with absolute time, and assumes that light behaves like a wave traveling through the ether.

3. Emitter Speed (Source Relativity)

The Emitter Speed hypothesis (historically proposed by Ritz and others) assumes that light propagates at speed c=1.0c = 1.0 relative to the source emitter that generated it.

  • If the source emitter is moving at velocity uu relative to an observer, the observer measures the speed of light from that source as c′=c±uc' = c \pm u.

  • This also preserves classical space and time. This model is valid if light is a particle.
