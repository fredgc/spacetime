Web & Android Release

      • Tutorial Flow & Markdown: Confirm rich typography (bold, italics, bullets) renders without raw markdown tokens. Verify animated pulsing highlights, card dragging/minimization, and “Do it for me”.

      • Google Drive Authentication: Verify Google Sign-in on web, saving diagrams, search query parsing (owner:me, partial names), and session persistence across reloads.

      • Unsaved State & Navigation: Verify leave-site warnings on unsaved edits, dialog confirmation on file changes, and unsaved state clearance on undo back to save checkpoints.

      • Version & Debug Docs Visibility: Verify the Help menu displays the active version (About Spacetime v${settings.fullVersion}) matching pubspec.yaml, and Developer Docs appear when “Enable Debug Mode” is toggled in Settings (under DEBUG_ENABLED=true).

      • Layout & Animations: Drag the split screen divider, advance time animation (tt), switch relativity modes (Lorentz/Ether/Emitter), and verify narrow mobile viewport reflow without overflow errors.

      • JsonSyntaxEditorDialog: Verify interactive error banners on malformed JSON and successful load on correction.

      • Tutorial Undo: Verify undoing object placement during a tutorial step reverts satisfaction status and disables advancing.

      • Help Menu Version: Verify dynamic version string rendering without hardcoded version fallbacks.
