# Politique de confidentialité

Spacetime respecte votre vie privée.

* **Traitement local** : Les calculs s'exécutent entièrement sur votre
  appareil.

* **Google Drive** : L'accès est utiliséexclusivement pour charger et
  sauvegarder vos fichiers.

* **Aucun suivi** : Aucune donnée personnelle n'est collectée.
