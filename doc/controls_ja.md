# ツールと操作方法

## 上部ツールバー

* **選択**：図上のオブジェクトを選択して編集・移動・削除します。

* **追加**：新しい時空オブジェクト（事象、時計、光円錐、列車など）を配置します。

* **光速度モデル**：

  * **ローレンツ変換**：光速度は全基準系で一定（$c = 1$）。

  * **エーテル仮説**：静止エーテルに対して光速度が一定。

  * **光源速度**：光速度は光源に対して相対的。

## 下部スライダー

* **時間（$t$）**：アニメーションの現在時刻を移動。

* **速度（$v$）**：観測者基準系の速度を$-0.99c$から$+0.99c$まで変更。
