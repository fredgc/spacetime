---
title: File Management
---

The left-hand drawer (accessible via the Menu icon) provides file and clipboard
options:

## 1. File Options

* **New**: Clears the current scene to start drawing on a blank canvas.

* **Open**: Prompts you to load a drawing from:

  * **Local Data**: Pick files from the device's storage.

  * **Google Drive**: Access synced drawings from your Google Drive files.

  * **Load from Clipboard**: A drawing can be saved as text and just pasted
    into the app this way.

* **Save**: Saves the current drawing to local storage, the clipboard, or
  Google Drive.

* **Save As**: Saves the current drawing to a new location (Local Data, Google
  Drive, or local file download).

## 2. Clipboard Integration

* **Copy to Clipboard**: Copies the scene serialized as a raw JSON string or as
  a shareable URL containing the encoded JSON data.

* **Paste from Clipboard**: Parses a copied JSON string or shareable URL from
  your clipboard and loads the drawing.

## 3. Upload / Download

* **Upload**: Import a JSON file from your computer's filesystem.

* **Download**: Export the active scene as a downloadable JSON file.
