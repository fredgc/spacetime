# Objets spatio-temporels

## Types d'objets

* **Événement** : Un point unique dans l'espace-temps $(x, t)$.

* **Personne, Train, Grange, Drapeau** : Objetsétendus ou ponctuels dotés
  d'une ligne d'univers.

* **Horloge** : Objet mesurant son temps propre le long de sa trajectoire.

* **Cône de lumière** : Rayons lumineux se propageantà$c = 1$.

* **Instant** : Surface de simultanéitépour un référentiel donné.
