# Outils et commandes

## Barre d'outils supérieure

* **Sélectionner** : Cliquez sur un objet pour le modifier ou le supprimer.
  Glissez sur le fond pour déplacer la vue.

* **Ajouter** : Placez de nouveaux objets spatio-temporels (événements,
  horloges, cônes de lumière, trains, etc.).

* **Mode de propagation** :

  * **Lorentz** : Vitesse de la lumière constante dans tous les référentiels
    ($c = 1$).

  * **Éther** : Propagation par rapportàunéther absolu.

  * **Émetteur** : Vitesse relativeàla source.

## Curseurs inférieurs

* **Temps ($t$)** : Fait défiler la coupe temporelle de l'animation.

* **Vitesse ($v$)** : Règle la vitesse du référentiel de l'observateur entre
  $-0.99c$ et $+0.99c$.
