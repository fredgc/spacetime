---
title: Gestión de Archivos
---

El panel lateral izquierdo (accesible mediante el icono de Menú) ofrece
opciones de archivo y portapapeles:

## 1. Opciones de Archivo

* **Nuevo**: Borra la escena actual para comenzar a dibujar en un lienzo en
  blanco.

* **Abrir**: Le solicita cargar un dibujo desde:

  * **Datos Locales**: Elija archivos del almacenamiento del dispositivo.

  * **Google Drive**: Acceda a dibujos sincronizados desde sus archivos de
    Google Drive.

  * **Cargar desde el Portapapeles**: Se puede guardar un dibujo como texto y
    pegarlo en la aplicación de esta manera.

* **Guardar**: Guarda el dibujo actual en el almacenamiento local, el
  portapapeles o Google Drive.

* **Guardar como**: Guarda el dibujo actual en una nueva ubicación (Datos
  Locales, Google Drive o descarga de archivo local).

## 2. Integración con el Portapapeles

* **Copiar al Portapapeles**: Copia la escena serializada como una cadena JSON
  sin procesar o como una URL compartible que contiene los datos JSON
  codificados.

* **Pegar desde el Portapapeles**: Analiza una cadena JSON copiada o una URL
  compartible desde el portapapeles y carga el dibujo.

## 3. Subir / Descargar

* **Subir**: Importe un archivo JSON desde el sistema de archivos de su
  dispositivo.

* **Descargar**: Exporte la escena activa como un archivo JSON descargable.
