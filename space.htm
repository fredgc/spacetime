Instructions:

Choose one of the items to add. An event is a point in space and time. An instant is a time slice in the current reference frame. A place is a point at rest in the current reference frame. A light cone is the set of all light rays leaving or entering an event.

The horizontal axis is the x-axis, the vertical axis is the t-axis. The transformation is done so that the center of the screen is the same in all reference frames.
